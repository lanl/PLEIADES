PLEIADES Documentation
======================

**PLEIADES** -- Python Libraries Extensions for Isotopic Analysis via Detailed Examination of SAMMY

PLEIADES is a Python package for setting up, executing, and analyzing SAMMY runs
for neutron resonance spectroscopy. If you are unfamiliar with SAMMY, please see
the `SAMMY website <https://code.ornl.gov/RNSD/SAMMY>`_.
